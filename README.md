# オンライン出版社 Pro - GIGA Edition

「オンライン出版社 Pro」は、GIGAスクール構想の教育現場（主に小学校）向けに開発された、児童が作文や物語を書き、先生が添削し、クラスで読み合うためのWebアプリケーションです。

児童が書いた文章はそのまま **縦書きの原稿用紙** や **挿絵入りの本** としてプレビュー・印刷でき、先生は原稿用紙の上で直接赤入れ（添削）ができます。完成した作品は「みんなの作品だな」に並び、児童どうしで感想を送り合えます。

バックエンドはGoogle Apps Script (GAS)、フロントエンドはReact + Tailwind CSSの単一HTMLです。**サーバーの契約やビルド作業は不要**で、学校のGoogle Workspaceアカウントでも個人用Googleアカウントでも利用できます。

- 📘 **画面ごとの詳しい操作手順は [MANUAL.md（操作マニュアル）](MANUAL.md) を参照してください。**

## 📌 このアプリでできること（早わかり）

| だれが | できること |
| --- | --- |
| 児童 | 題名・学年組・名前・本文を書く／挿絵を追加して形やサイズを変える／原稿用紙・本の2種類でプレビューする／印刷する／先生に提出する／先生の添削を読んで「修正完了」にする |
| 先生 | 提出物を一覧で見る／検索・絞り込みをする／原稿用紙上をドラッグして赤線と添削コメントを付ける／AI（Gemini）に添削案を作らせる／前回からの変更点を差分表示する／「完了」「再提出」を切り替える／まとめてAI添削・完了・印刷する |
| クラス全員 | 「提出済」「完了」の作品を本棚から選び、全画面のブックリーダーでページをめくって読む／感想コメントを送る |

作品データ（作文・添削・感想）は**Googleスプレッドシート**に、挿絵画像は**Googleドライブ**に保存されます。どちらも初回起動時に自動生成されるため、事前準備は不要です。

### 作品がたどる4つのステータス

作品は必ずこの4つのどれかの状態にあり、状態によって「誰が編集できるか」「どこに出るか」が変わります。

| ステータス | 児童の編集 | 先生の一覧 | みんなの作品だな | バッジの色 |
| --- | :--: | :--: | :--: | --- |
| 下書き `draft` | できる | 出ない | 出ない | グレー |
| 提出済 `submitted` | **できない**（コピーは可） | 出る | **出る** | 青 |
| 再提出 `rework` | できる | 出る | 出ない | オレンジ |
| 完了 `completed` | **できない**（コピーは可） | 出る | **出る** | 緑 |

状態が変わるのは、次の操作のときだけです。

| 操作する人 | 操作 | 変化 |
| --- | --- | --- |
| 児童 | 「提出する」 | 下書き → **提出済**（「再提出」の作品は**「再提出」のまま**変わりません） |
| 先生 | 「完了」（`C` キー） | どの状態からでも → **完了** |
| 先生 | 「再提出」（`R` キー） | どの状態からでも → **再提出**（完了にしたあとで差し戻すこともできます） |
| 児童 | 「コピーして新しく書く」 | 元の作品はそのまま。**下書き**の新しい作品が1つ増えます |

> つまり、児童が自分で「完了」にすることはできず、先生が「完了」を押すまで作品は完成扱いになりません。
> また「提出済」と「完了」はどちらも**みんなの作品だな**に並びます（提出した時点でクラスに公開されます）。

## ✨ 主な機能

アプリは **児童モード / みんなの作品だな / 先生用** の3つで構成されます。教師・児童はGoogleアカウントで利用し、先生用は学級を作成した教師本人だけが開けます。学校アカウントの学級には同じ組織ドメイン、個人用アカウントの学級には個人用Googleアカウントで参加します。

### 👧👦 児童向け機能（児童モード）

* **執筆エディタ**: 「だいめい」「がくねん・くみ」「なまえ」「本文」を入力します。本文の下に**改行を除いた文字数**がリアルタイムで表示されます。漢字にはふりがな（ルビ）が振られています。

* **クラウド自動保存（保存ボタンはありません）**: 入力が **20秒** 止まると自動でサーバー（スプレッドシート）に保存されます。本文欄の下に、いまの状態が5種類のどれかで表示されます。

  | 表示 | 意味 |
  | --- | --- |
  | ✏️ 編集中 | まだ保存されていない変更がある |
  | 🔄 保存中... | サーバーへ送信中 |
  | ☁️ クラウド保存済 | 保存完了 |
  | 🚫 オフライン (端末に一時保存) | ネットが切れている。内容は端末に残り、復帰時に自動送信 |
  | ⚠️ エラー (端末に一時保存) | 送信に失敗。内容は端末に残っている |

  * タブを閉じる・別アプリに切り替えるなど画面が非表示になった瞬間にも即座に保存されます（Chromebook のタブ破棄対策として `pagehide` でも確定します）。
  * 最後に編集していた作品は端末のブラウザにも控えられ、**次に同じ端末で開いたときに自動で復元**されます（`localStorage`）。
  * オフライン時や通信失敗時は端末内（localStorage）に一時保存し、**オンラインに復帰したタイミングで自動送信**します。
  * 「提出済」「完了」の作品は編集がロックされるため、自動保存も行われません。

* **挿絵の追加と編集**: 画像を選ぶと端末側で**幅800px以下のJPEGに縮小**してからGoogleドライブへアップロードします。挿絵ごとに次の設定ができます。
  * 配置するページ番号の指定（「本」モードの何ページ目に置くか）
  * 大きさ 30〜150%
  * 切り抜きの形 8種類（しかく／かどまる／まる／ふわふわ／ひしがた／ほしがた／はっかくけい／チケット）
  * 並べ替え（同じページ内での表示順）、削除
  * ※ 挿絵が表示されるのは「**本**」モードと本の印刷のみです。原稿用紙モードには表示されません。

* **2種類のプレビュー**:
  * **原稿用紙モード**: 縦書き・右から左のマス目表示。1行目に題名、次の行に学年組と名前が入ります。設定で **20字×20行（高学年）/ 15字×16行（低学年）** を切り替えられ、禁則処理は **追い出し / ぶら下がり** の2方式から選べます。
  * **本モード**: 1ページ目が表紙（題名・学年組・名前）、2ページ目以降が本文（35字×13行）。指定したページの上部に挿絵が並びます。

* **印刷**: プレビューの「印刷」ボタンから **A4横** で出力します。原稿用紙表示中は原稿用紙のレイアウト（中央に綴じ代付き）、本表示中は見開き2ページのレイアウトで印刷されます。

* **提出と作り直し**: 「提出する」で先生に提出します。提出済・完了の作品は編集できなくなりますが、「**コピーして新しく書く**」で挿絵ごと複製し、新しい下書きとして書き直せます（添削と感想は引き継ぎません）。
  * ※ **提出はネットにつながっているときだけ**できます。オフラインでは「サーバーと通信できませんでした」と表示されます（下書きの自動保存はオフラインでも端末に残ります）。

* **先生からの添削確認**: 赤いマークの付いた文字をタップするとコメントが開き、「修正完了（赤線を消す）」で1件ずつ消していけます。本文を書き直しても、添削の位置は自動で追従します。

* **先生の操作をお知らせ**: 「提出済」の作品を開いている間は **1分おき** にサーバーを確認し、先生が「完了」「再提出」にしたり添削を更新すると、メッセージを表示して画面を自動更新します。

### 🏫 先生向け機能（先生モード）

* **提出一覧（管理画面）**: 下書き以外（提出済・再提出・完了）の作品が一覧表示されます。
  * キーワード検索（**名前・題名・本文**を対象）
  * ステータス絞り込み（**完了以外**（初期値）／すべて表示／提出済／再提出／完了）
  * 更新日の期間指定（開始日〜終了日）
  * 前回添削時から本文が変わっている作品には「差分あり」アイコンが付きます

* **直感的な添削UI**: 原稿用紙プレビュー上で文字を**ドラッグ**して範囲を選び、コメントを入力すると赤線として追加されます。既存の赤線をクリックすると削除できます。タッチ端末では**長押ししてからなぞる**ことで範囲選択できます。

* **AI添削アシスト**: Gemini API（`gemini-2.5-flash`）が誤字脱字の指摘や改善点・良い点を小学生向けの言葉で提案し、`【AI】` 付きの赤線として本文の該当箇所に自動で追加されます。選択した作品をまとめて処理する**一括AI添削**にも対応しています。
  * ※ AIの指摘のうち、本文中に一致する箇所が見つかったものだけが赤線になります。
  * ※ 利用にはGemini APIキーの設定が必要です（後述）。

* **ステータス操作**: 「完了」「再提出」をワンクリックで切り替え。画面は即座に更新され（楽観的UI）、通信に失敗した場合は自動で元の状態に戻ります。

* **差分（Diff）表示**: 前回添削したときの本文と現在の本文を比較し、追加箇所を緑、削除箇所を赤の取り消し線でハイライトします。

* **一括操作**: チェックを入れた複数作品に対して、一括AI添削・一括「完了」・一括印刷を実行できます。

* **キーボードショートカット**: `?` キーで一覧が開きます（後述）。

### 🎨 みんなの作品だな（ギャラリーモード）

* 「提出済」または「完了」の作品が**本棚**として並びます。感想が付いている作品には件数バッジが表示されます。

* 本を選ぶと**全画面のブックリーダー**が開きます。縦書きの本なので**右から左へ**めくります。
  * `←` キー / 画面左の矢印 / 左へスワイプ → **次のページ**
  * `→` キー / 画面右の矢印 / 右へスワイプ → **前のページ**
  * `Esc` キー / 左上の「一覧にもどる」 → 一覧へ
  * ※ 画面左右の矢印はPCサイズ（横1024px以上）のみ。狭い画面では本の下にページ送りボタンが出ます。

* 読んだ作品に**感想（コメント）**を送れます。名前を空欄で送ると「名無し」として投稿されます。

## 🛠 技術スタック

* **Frontend**: React 18 (CDN), Tailwind CSS (CDN), Babel Standalone, Bootstrap Icons, Google Fonts (Zen Maru Gothic / Shippori Mincho), diff-match-patch
* **Backend**: Google Apps Script (GAS) — `code.gs`
* **Database / Storage**: Google Sheets（作文データ・交流コメント）, Google Drive（挿絵画像）
* **AI Integration**: Google Gemini API (`gemini-2.5-flash`)

ビルド工程はありません。`code.gs`・`index.html`・`appsscript.json` をGASプロジェクトへ配置して動作します。

### 自動生成されるデータ

教師が共通入口から初回アクセスしたとき、**その教師のマイドライブ**へ以下が自動作成されます。教師ごとに保存先は完全に分離されます。

| 種類 | 名前 | 内容 |
| --- | --- | --- |
| スプレッドシート | `オンライン出版社Pro_データベース` | 作文データ13列（非表示の作者キーを含む）と交流コメントデータ。Workspaceは同一ドメイン、個人用はリンク共有 |
| Driveフォルダ | `オンライン出版社Pro_画像データ` | 挿絵画像。スプレッドシートと同じ共有範囲 |
| User Properties | `CLASS_CODE` / `GEMINI_API_KEY` / `SPREADSHEET_ID` / `IMAGE_FOLDER_ID` | 教師ごとの学級コード、APIキー、保存先ID |
| Script Properties | `TENANT_<学級コード>` | 学級コードから教師別保存先を解決するレジストリ（メールアドレスはSHA-256ハッシュのみ保存） |

## 📲 PWAとしてインストールする（Chromeから「アプリ」にする）

### 方法1: Chromeのメニューからインストール（いちばん簡単）

PC / Chromebook のChromeでウェブアプリのURL（`/exec`）を開き、右上のメニュー（︙）から
**「キャスト、保存、共有」→「ページをアプリとしてインストール」** を選ぶと、独立ウィンドウで起動するアプリとしてインストールできます。

> Google Apps Script のウェブアプリはGoogleのラッパーページ（iframe）内で動作する仕様のため、この方法ではアイコン等は既定のものになります。専用アイコン付きの本格的なPWAにしたい場合は方法2を使ってください。

### 方法2: 同梱のPWAシェル（`pwa/` フォルダ）を使う

本リポジトリの `pwa/` フォルダは、GASのウェブアプリを全画面で包む**インストール可能なPWAシェル**です（マニフェスト・Service Worker・アイコン同梱）。アプリ本体は常にネットワークから読み込むため、シェルだけがキャッシュされます。

1.  このリポジトリをフォークし、GitHubの **Settings → Pages** でGitHub Pagesを有効にします（もしくは `pwa/` フォルダを任意の静的ホスティングに配置します）。

2.  `https://<ユーザー名>.github.io/<リポジトリ名>/pwa/` にアクセスします。

3.  `pwa/config.js` の `gasWebAppUrl` にデプロイ済みGAS URL（`/exec`）を設定します。利用者はGAS URLを入力しません。

    * 先生は「先生として学級を準備する」を押します。教師のDriveにDBが作成され、8文字の学級コードが表示されます。
    * 児童は同じ入口で学級コードを入力します。配布用URL `.../pwa/?class=<学級コード>` なら入力を省略できます。
    * 学級を変えるときは、アプリ右下の「学級を変える」を押します。

4.  アドレスバーのインストールアイコン、または画面内の「📲 アプリとしてインストール」ボタンからインストールできます。ボタンはアプリ起動後も右下に出るため、2回目以降に開いた児童でもインストールできます。

    *   **Androidタブレット**: Chromeのメニュー →「ホーム画面に追加」→「インストール」
    *   **iPad / iPhone**: Safariの共有メニュー →「ホーム画面に追加」（`beforeinstallprompt` が無いためボタンは出ません）

    → 児童・先生向けの詳しい手順は [MANUAL.md §7](MANUAL.md#7-アプリとしてインストールするpwa) にあります。

5.  シェルを更新したときは `pwa/sw.js` の `APP_VERSION` を必ず上げてください。上げ忘れると、児童の端末に古い画面が残り続けます。バージョンを上げると、児童の画面に「あたらしい バージョンが あります／さいしんに する」が出ます。

> **⚠️ フォークして使う場合は `pwa/manifest.webmanifest` の3つの値を必ず書き換えてください。**
>
> ```json
> "id":        "/{あなたのリポジトリ名}/pwa/index.html",
> "start_url": "/{あなたのリポジトリ名}/pwa/index.html?source=pwa",
> "scope":     "/{あなたのリポジトリ名}/pwa/"
> ```
>
> `github.io` は1つのアカウントの全リポジトリが**同じドメイン（オリジン）を共有**します。
> そのため `id` を元のままにしていると、同じ端末に入れた別のアプリと取り違えられ、
> 「アイコンを押したら違うアプリが立ち上がる」事故が起きます。
> なお `id` は「インストール済みアプリの本人確認票」なので、**一度公開したあとは変えないでください**
> （変えると、すでに入れた端末では別のアプリとして扱われます）。

## 🚀 導入手順（セットアップ）

このアプリはGoogle Apps Script (GAS) のWebアプリとして動作します。データベースとなるスプレッドシートや画像保存用フォルダは、**初回起動時に自動で生成（自己修復）される**ため、複雑な初期設定は不要です。

### 1. GASプロジェクトの作成

1.  [Google Apps Script](https://script.google.com/) にアクセスし、「新しいプロジェクト」を作成します。
2.  プロジェクト名を「オンライン出版社 Pro」などに変更します。

### 2. コードの配置

1.  デフォルトで存在する `コード.gs` に、本リポジトリの `code.gs` の内容をコピー＆ペーストします。
2.  左側の「＋」ボタンから「HTML」を選択し、ファイル名を `index` にして作成します（`index.html` になります）。
3.  作成した `index.html` に、本リポジトリの `index.html` の内容をコピー＆ペーストします。
4.  プロジェクト設定でマニフェストを表示し、`appsscript.json` の内容を反映します。

### 3. Webアプリとしてデプロイ

1.  右上の「デプロイ」>「新しいデプロイ」をクリックします。
2.  種類の選択（歯車アイコン）から「ウェブアプリ」を選択します。
3.  以下の設定でデプロイします：
    *   **説明**: （任意）
    *   **実行するユーザー**: `ウェブアプリにアクセスしているユーザー`
    *   **アクセスできるユーザー**: `Google アカウントを持つ全員`
4.  「デプロイ」をクリックします。
5.  初回は「アクセスを承認」の警告が出ます。「詳細を表示」>「オンライン出版社 Pro（安全ではないページ）に移動」から許可を行ってください。

> この設定が必須です。「自分」として実行すると、全教師がデプロイ所有者の保存先を共有してしまいます。

### 4. 初期設定と動作確認

1. `pwa/config.js` に発行されたウェブアプリURLを設定し、GitHub Pagesを更新します。
2. 共通入口で「先生として学級を準備する」を押し、Googleの権限画面を許可します。
3. 表示された学級コードを児童へ配ります。
4. AI添削を使う場合だけ、歯車から教師自身のGemini APIキーを登録します。

> **旧版から更新する場合**：旧版のScript Propertiesにある単一の`SPREADSHEET_ID`は、自動では教師別テナントへ移しません。誤った教師が先に取得する事故を防ぐためです。旧データはバックアップとして保持し、必要な行だけ新しい教師別スプレッドシートへ管理者がコピーしてください。

> **学校管理者への確認**：この方式は利用者本人としてDriveとSheetsを操作するため、教師・児童とも初回にOAuth承認が必要です。管理コンソールで未承認アプリやDrive共有が制限されている場合は、全校配布前に検証用アカウントで承認・保存・画像投稿を確認してください。

## 🚧 このアプリで「できないこと」

期待とのズレが起きやすい点をあらかじめ挙げます。いずれも現在の仕様です。

| できないこと | 実際にはこうなります |
| --- | --- |
| **同じ作品を2人で同時に編集する** | 排他制御はありません。あとから保存したほうの内容で上書きされます（後勝ち）。1人1作品での利用を前提としています |
| **オフラインで提出する** | 「提出する」は通信が必要です。オフラインでは下書きが端末に残るだけで、先生には届きません |
| **アプリから作品を削除する** | 削除ボタンはありません。スプレッドシートの「削除日時」列に値を入れて非表示にします |
| **感想（コメント）を消す・直す** | アプリからはできません。「交流コメントデータ」シートの行を直接削除します |
| **クラス・学年で表示を分ける** | 一覧は常に全件です。「学年・クラス」欄は表示用の文字列で、絞り込みは先生画面のキーワード検索で行います |
| **Google Workspaceを使わずに利用する** | 対応しています。教師・児童とも個人用Googleアカウントでログインし、同じ学級コードを使います |
| **先生が児童へ自由文のコメントを送る** | 現在の画面にはありません（添削の赤線にコメントを添える形で伝えます）。スプレッドシートの「先生コメント」列は将来用の予備で、アプリからは書き込まれません |
| **提出物をCSV等で書き出す** | 書き出し機能はありません。スプレッドシートをそのままダウンロードしてください |

## 🔐 セキュリティと運用上の注意

利用前に、次の仕様を理解したうえで運用ルールを決めてください。

* 教師本人はGoogleアカウントと教師別レジストリで判定します。共通パスワードはありません。
* 児童は学級コードに加え、教師と同じGoogle Workspaceドメインであることをサーバー側で確認します。
* 児童の作品には非表示の作者キーを記録し、「開く」一覧は本人の作品だけを返します。ギャラリーには提出済み・完了作品だけを表示します。
* スプレッドシートと画像フォルダは、Workspaceでは原則「学校ドメイン内・リンクを知っているユーザーが編集可」、個人用アカウントでは「リンクを知っているユーザーが編集可」です。組織ポリシーでドメイン共有が使えない場合もリンク共有を試します。個人が特定できる写真等の扱いには引き続き注意してください。
* **作品を削除する機能はアプリ内にありません。** スプレッドシート「作文データ」の「削除日時」列に値（日付など）を入力すると、その行はアプリ上に表示されなくなります。

### OAuthスコープについて

`appsscript.json` で必要スコープを明示しています。Apps Scriptの`DriveApp.createFolder`・共有設定・画像作成は `auth/drive` を要求するため、教師だけでなく児童にも初回承認が表示されます。学校のGoogle Workspace管理者によるアプリ許可を先に行う運用を推奨します。組織ポリシーやサードパーティCookie制限で埋め込み表示に失敗する場合は、右下の「別画面で開く」でGASを直接開いて承認してください。

## ⚠️ 制限とクォータ

Google Apps Script には実行量の上限があります。**1クラス（40人程度）での通常利用なら問題になりませんが**、
学年一斉・全校一斉で使う前に、次の点を把握しておいてください。
（正確な数値はアカウントの種類で変わります → [Google公式のクォータ表](https://developers.google.com/apps-script/guides/services/quotas)）

| 項目 | 起きること | 目安と対処 |
| --- | --- | --- |
| **同時実行数** | 一斉に「提出」を押すと、順番待ちが発生します | GASの同時実行には上限があります。書き込みは `LockService` で1人ずつ通しているため、待ち時間が10秒を超えると「サーバー混雑中」と表示されます。もう一度押せば保存されます（データは壊れません） |
| **スクリプトの実行時間** | 1回の処理が長すぎると強制終了します | 一括AI添削を大量（20件以上など）にかけると上限に近づきます。**10件程度ずつに分けて**実行してください |
| **Gemini APIの利用量** | AI添削が「実行に失敗しました」で止まります | 無料枠には1分あたり・1日あたりの回数制限があります。時間をおくか、有料プランを検討してください |
| **Driveのファイル作成数** | 挿絵がアップロードできなくなります | 1日に作成できるファイル数に上限があります。挿絵は1枚ごとにDriveのファイルになります |
| **Driveの容量** | 同上 | 挿絵は**自動では消えません**。年度末に `オンライン出版社Pro_画像データ` フォルダを確認してください |
| **スプレッドシートのセル数** | 保存に失敗します | 1シート1,000万セルが上限です。本アプリは1作品=1行（12列）なので、通常は到達しません |
| **本文の1セルあたりの文字数** | 長すぎる作文が途中で切れます | スプレッドシートの1セルは50,000文字までです。原稿用紙400字詰めで125枚相当のため、実用上は問題ありません |

### 運用の目安

* **1クラス40人が同時に使う**：想定内です。提出が集中する場面で数秒の待ちが出ることがあります。
* **学年3クラス120人が同時に使う**：提出のタイミングをずらすことを推奨します。
* **一括AI添削**：10件ずつに分けてください。全件を一度にかけると実行時間の上限に達します。

## 💡 ショートカットキー（先生用画面）

先生用画面では、キーボード操作で効率的に作業ができます（`?` キーで一覧表示）。

| キー | 動作 |
| --- | --- |
| `↑` / `↓` | 児童（作品）の切り替え |
| `V` | プレビューの切り替え（原稿用紙 → 本 → 差分） |
| `S` | 表示中の作品を一括選択 / 解除 |
| `U` | データの更新 |
| `A` | 表示中の作品のAI添削 |
| `Shift + A` | 選択した作品の一括AI添削 |
| `P` | 表示中作品の印刷 |
| `Shift + P` | 選択した作品の一括印刷 |
| `C` | 完了にする |
| `R` | 再提出にする |
| `?` | ショートカット一覧の表示 / 非表示 |
| `Esc` | 開いているモーダルを閉じる |

※ 入力欄（テキストボックス・検索欄など）にカーソルがあるときは、ショートカットは動作しません。
